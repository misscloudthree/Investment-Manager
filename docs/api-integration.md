# 後續資料串接與待決事項

目前沒有 API adapter、憑證設定、重試／快取、排程或資料儲存。以下是待驗證的資料來源方案，不代表端點已測通或可無限制商用。資料來源不一定有統一 API；必要時以官方文件或有來源的人工匯入支援研究。

| 優先度／來源 | 用途 | 入口與待確認事項 |
|---|---|---|
| P0 TWSE | 商品主檔、上市日行情／成交、交易狀態、公司行動及可得 ETF 資料 | https://openapi.twse.com.tw/ 、https://www.twse.com.tw/ ；核對欄位、歷史窗口、更新時間、再利用授權與流量限制；不是即時報價承諾 |
| P0 TPEx | 上櫃主檔、成交／行情、交易狀態、ETF 與公司行動 | https://www.tpex.org.tw/openapi/ ；上市與上櫃欄位正規化、交易日與量能單位須測試 |
| P0 公開資訊觀測站／政府開放資料 | 合併財報、月營收、重大訊息、持股／治理與財報附註 | https://mops.twse.com.tw/ 、https://data.gov.tw/ ；確認可用資料集及下載方式，不假設所有附註均有穩定 API；不繞驗證碼或反爬機制 |
| P0 投信／基金發行人與指數編製商 | ETF 公開說明書、完整持股、每日正式 NAV、費率／實際費用、收益分配組成、指數規則與含息基準 | 依商品主檔建立官方 URL 清單，無統一 API；逐家確認頻率、可得歷史、時區與授權；主動式持股披露可能不同 |
| P1 FinMind 或其他授權金融資料 API | 歷史價量、財務欄位與公司行動補齊及交叉核對 | https://finmindtrade.com/analysis/#/api ；評估套餐、token、欄位覆蓋／延遲、再散布及商用限制；平台轉載同一官方資料非獨立事實來源 |
| P1 台灣央行／主計總處／國發會／財政部 | 利率、匯率、GDP、物價、景氣與出口資料 | https://www.cbc.gov.tw/ 、https://www.dgbas.gov.tw/ 、https://www.ndc.gov.tw/ 、https://www.mof.gov.tw/ ；取官方發布／修訂日期，確認可機讀介面 |
| P1 公司 IR、法說與公開年報 | 分部、產能、策略及治理證據 | 每公司官方網址與公告版本，文件擷取與頁碼引用；不可用新聞摘要冒充已讀原文 |
| P2 海外官方／授權資料（例如 FRED） | 海外底層資產、殖利率／信用／總經，補台灣跨境 ETF 分析 | https://fred.stlouisfed.org/docs/api/fred/ ；依商品需求接入，不預設所有資料可商用或無 API key |
| P2 授權新聞／事件服務、集保資料 | 事件發現與股權分散等輔助訊號 | 依預算選擇；新聞對回官方公告去重，集保持股分布不可冒稱法人即時交易 |
| 私有輸入（非交易 API） | 實際持倉／現金／核准 thesis | 使用者確認的檔案匯入或未來唯讀介面；不需要券商下單權限，不接自動交易 |

## 最小可行資料需求

篩選：商品主檔、交易狀態、最近行情、20／60 交易日量能／法人資料、至少 12 個月含息報酬、財報與月營收、同組比較母體。研究：年季報原文與附註、現金流／資本支出、股數、法說／重大訊息、同業、公司行動。ETF：指數／策略、費用、NAV／含息序列、持股、配息組成、流動性；欠缺完整持股時不宣稱完整穿透。

用官方文件／匿名 CSV 也可進行人工輔助研究，不需一次買齊所有服務；自動執行前必須完成來源與運行測試。API key 只能安全注入環境／秘密管理，文件與範例不保存值。不要因沒有 token 變數就宣稱公開資料或 GitHub 無法讀取。

## Adapter 設計與驗證待辦

- 定義 raw → normalized 欄位 mapping、來源 ID、時間／幣別／單位、公告時點與可用性；不把無資料改成零。
- TLS 驗證、逾時、指數退避、限流、快取與 idempotent snapshot；不安裝未知 scraper 或執行第三方下載工具。
- 用公開少量實際資料比對官方原文，加入資料漂移、停牌、重編、跨境 NAV 時差、ETF 分割與前導零案例。
- 分別測試 schema、計算、來源 adapter、端到端報告；標示合成樣本與真實樣本。依 PROJECT 完成後才可宣稱可執行。

待決：投資期限、基準與篩選母體、資料預算／授權、最低流動性與風險限額、私有儲存與持倉匯入、核准介面、排程時間、通知渠道／冷卻規則。這些不阻礙本階段規格交付，未核定前不可自行代設為使用者已核准政策。

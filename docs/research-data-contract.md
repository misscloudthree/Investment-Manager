# 研究資料與報告共用契約

所有 Skill 執行前必讀。此規範是台灣在地化選擇；不是上游績效或模型準確率的背書。

## 身分、日期與來源

- 代碼一律當字串，保留 `0050` 等前導零及 ETF 字母後綴。至少記錄代碼、名稱、交易所（TWSE/TPEx）、資產類型、交易幣別；不得只靠 `.TW` / `.TWO` 或名稱猜商品。
- 預設研究台灣上市／上櫃普通股與台灣掛牌 ETF；興櫃、權證、ETN、特別股另列，不混排。ETF 掛牌幣別不等於底層風險幣別。
- 使用 Asia/Taipei、ISO 日期；民國年轉西元但保留原始欄位。區分資料所屬期間、公告日、擷取時間與研究截止時間；歷史研究只用當時已公開版本，保留重編版本，避免前視偏誤。
- 報告開頭列：研究時間、截止時間、最近交易日、價格日期、財報期間、資料覆蓋率、信心（高／中／低）、缺口。非交易日以最近交易日收盤價並標示，不稱即時報價。
- 每個核心數字附來源 ID。來源表欄位：ID、提供者、URL／文件頁碼、欄位、期間、公告時間、擷取時間、單位、幣別、取得方式（API／官方文件／使用者提供）、可信度。不同欄位不可共用模糊的「截至今日」。
- 來源順序：交易所／公開資訊觀測站／投信公開說明書與公告 > 公司法說與 IR > 可追溯授權資料商 > 新聞。新聞可發現線索，不能替代財報原文。
- 交叉驗證股價、股數、市值、營收、淨利與 NAV。兩個網站若轉載同一供應商不算獨立。來源衝突時對齊日期、合併／個體、幣別與重編狀態，保留雙值及採用理由，不平均。差異逾 1% 為調查旗標，非自動判定造假；未解決且影響結論時暫停排名／估值。

## 計算與缺值

- 價格為每股／每受益權單位；股數及單位數不可與「張」混用。量能記錄股／單位與成交金額；不要假定所有產品每張皆相同。金額明列元／千元／百萬元／億元，1 億 = 100,000,000 元。
- 財報預設合併報表；EPS 使用歸屬母公司普通股股東的稀釋口徑並記錄差異。TTM 為最近四個獨立季度，不可加總累計財報；現金流累計值先差分成單季。年報與四季和有差異時調查調整分錄。
- 市值 = 同日股價 × 同日流通在外股數（排除庫藏股並說明口徑）；不得拿加權平均 EPS 股數當期末股數。
- 非金融業 FCF = 營業現金流 − 購置不動產廠房設備與無形資產現金支出（以正值支出計），併購另列；ROE 用平均權益、ROIC 用 NOPAT／平均投入資本並公開定義。母公司淨利與總權益不可混算而不揭露。
- EPS ≤ 0 的本益比、負權益的 ROE/PB、不適用金融業的 EV/EBITDA 不得拿來比較「便宜」。基期 ≤ 0 時 EPS 成長率列 N/A，改列絕對損益變動。缺值不是 0。
- 使用可檢查算式或已審查的本地計算工具驗算；報告保留輸入、公式、輸出、四捨五入。不得假稱已執行上游未安裝的 Python 工具。
- 報酬比較用同幣別、同期間、相同再投資及稅前／稅後口徑；拆股、減資、配股、除權息及 ETF 分割先調整。不可把已含息還原序列再加股息。
- 預設時效政策：行情須為最近可得交易日；月營收、財報、持股與 NAV 須為截止時間前最近已公告版本。較舊資料可做歷史分析，但必須標日期；無法確認最新版本就列「未確認最新」並降低信心。海外 ETF 持股、指數與 NAV 時區不同，不得直接宣稱套利。
- 網路或 API 不可用時，可使用有來源與日期的 CSV、財報或投信月報。沒有關鍵資料只輸出研究框架、缺口及可驗證部分，不輸出虛構數值、正式排名或目標價。

## 證據與結論

事實、計算、假設、推論分開標示。每個核心論點連到證據、最強反證與失效條件（指標、門檻、觀察窗口、資料源、重評動作）。門檻須在觀察前設定，不能看到結果後搬動紅線。

信心高：關鍵一手來源完整、計算可重現且無重大未解衝突；中：主要資料可得但有次要缺口；低：關鍵缺值、來源衝突或僅部分持股。信心描述資料及推理品質，不是獲利機率。任何研究分數都不代表保證報酬或自動下單訊號。

報告最後列：已驗證／未驗證、主要風險、失效條件、下次事件與檢查日、來源表、計算附錄。金融法規、交易稅、補充保費及配息所得分類需依研究日官方規則與投資人身分確認，不硬編固定稅率。


## Task 2.1 決策資料與預測品質

`investment_decision` 的 checklist 指的是是否具備可追溯資料／合理推理，不是預測一定正確。verified 條目須有來源；覆蓋率 = verified／非 not_applicable 條目，缺資料／衝突仍列分母；Not Assessed 不等於通過。重要價格、估值、報酬、風險及個人資料缺口不能靠其他完整欄位抵銷。

- 決策 metrics 明列交易價、NAV、實際總費用、歷史含息總報酬、TD/TE、MDD、年化波動及底層盈利／估值。報酬、費用、波動、drawdown 一律以小數比率交換（0.01=1%）；MDD 用負值。PE 是倍數，價格／NAV 記 TWD 或實際幣別與時點。
- 預測參數是可挑戰的假設，不標成已驗證事實；每個參數須有來源日期與選值理由。沒有可比底層盈利或指數估值時，不以基金淨值、殖利率或歷史 CAGR 代替。跨境估值與價格的時點差必須說明，未知時間無法支持精準即時折溢價。
- 歷史含息序列不能再加股利；已費後績效不能再扣 TER／TD；已轉換的幣別不能再疊 FX。模型 cost_basis 與含息／稅務口徑須顯式記錄，避免重複計算同一成本。
- 歷史回撤不等於未來最壞損失；年化波動不是虧損概率。情境只表示「若這組輸入成立」的結果，不得生成沒有校準依據的勝率或以精確小數製造確定性。
- 個人持倉、風險／流動性資料缺失時，Gate 3 Not Assessed；資金金額和五年期間不能替代這些資料。缺個人資料仍可做產品與進場研究，但最終個人投資建議降為 Insufficient Evidence。
- 「有證據所以等待」與「沒有證據所以不能決策」分開：前者必須有價格、風險、報酬與重評條件；後者列出決定性資料及官方取得方法，不猜合理買價。

新 Schema 2.0 與 Python 一致性驗證只能檢查欄位／引用、閘門與數值算式；不能證明來源真實、假設合理或 ChatGPT 實際遵守方法。反方審查與人工原文／計算核對仍是必要驗收。


## Task 2.2 批次資料補充

新增 normalized snapshot／campaign 契約 1.0，見 `schemas/market-snapshot.schema.json`、`schemas/research-campaign.input.schema.json`、`schemas/research-campaign.output.schema.json` 與 `BATCH_RESEARCH.md`。這些是 ResearchRun／初篩資料，不能替代 Proposal 2.0 或 Task 3 核准資料庫。snapshot、截止、政策與版本凍結；一個母體每檔都有 ledger，缺漏／失敗不刪除。完整與 sample 範圍必須明示，最新主檔不能作歷史成分。

metric.as_of 是比較日的已知狀態日，財報期放 period；沒有公告證據不得把期末當可得日期。參與排名的各資料須同組最新行情日、正確單位且口徑／窗口可比；窗口由來源／匯入者驗證，程式檢查日期與單位不等於已驗證所有經濟口徑。未知原始發布時間 null，不製造午夜 timestamp。官方 raw 與 SHA 保存於 run；檔案不得越界或缺失。資料／政策有變更另開 campaign。

initial TWSE adapter 僅主檔／單日行情／PE/PB，不能完成品質、五因子或 ETF 進場分析。部分基本資料可以進入有限 profile 研究排序，必須使用 profile 名稱與缺口；不得把 basic 分數寫進舊五因子 composite，不能把 vehicle 優先度宣稱基金品質／底層便宜。實測官方連線仍受本環境 403 限制。

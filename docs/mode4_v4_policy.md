# Mode 4 v4 — 每日機率優勢交易與帳本規範
生效：2026-10-28（Asia/Taipei）。本文件取代 v3 的「每週最多一筆／每週固定停利2–3%」作為研究目標；保留紙上帳戶 NT$100,000，無槓桿。實際交易與紙上交易嚴格分開。

## 目標與決策
優先最大化「扣除手續費、證交稅、滑價、未成交後的長期可重複期望值」，而非強迫每天交易。研究交易頻率目標為每週2–5筆，但**不是下單配額**；樣本外不支持正期望值時維持 NO TRADE / CONDITIONAL。不可因交易次數目標而降低資料品質。採三類互斥可比較策略：突破續強、趨勢回測、均值回歸；每類明列預先定義的條件、停損及時間退出。尚未回測驗證的訊號只能稱「研究假設」，不可宣稱正期望值或可靠勝率。

## 風險與限制
紙上總資金 NT$100,000；初始單筆預算風險 NT$300–500（滑價費稅全含），同時在險未平倉風險合計上限 NT$1,000；總名目曝險不得超過可用現金；最多1個紙上持倉（先驗證後才另行授權放寬），僅台股現股/股票ETF、不融資、不槓桿；零股要處理最小跳動、最低手續費與實際撮合。最大持有時限按策略設定，預設1–5個有效交易日；不預設固定每週五出場。跳空穿停損可能超出預算，應揭露。
交易計畫須列：策略類型、訊號所據 K 線日期及訊號日、進場觸發與最高限價、量、停損、停利或依規則出場、失效條件、退出截止、成本與滑價、淨盈虧／整筆資金報酬／淨R比。未觸發 0 股。紙上成交須具明確可重算的撮合規則，**有日 K 觸及不代表成交**，尤其同一日進出場先後無法推定時標記 ambiguous_no_fill。

## 資料與驗證
先以 GitHub connector 讀取 main:data/mode4_latest.json（不是 lastest），檢查 generated_at_taipei / latest_bar_date / date_counts / coverage / selected_C / errors / 各 symbols 的 >=60 根 OHLCV。候選 A=0050,2881,2317,2382,2303；B=2330,2308,2891,2357,3711；C 採 JSON 的 selected_C 及事前規則，揭露實際覆蓋。資料源 Yahoo Finance 第三方非官方；校驗時區、日期、缺價、跳空、除權息、ETF 交易限制、重大事件及大盤。重要異常（例如 0050/0056 2026/10/27 日K缺列、歷史量修訂）先隔離受影響標的，不可無條件自稱25/25可交易。
每次報告都可提供研究候選，但只有通過必要資料及事件閘門的才是 TRADE PLAN READY；若訊號仍待觸發可用 CONDITIONAL；NO TRADE 必須有充分候選審查；資料不全標示 PARTIAL COVERAGE / DATA BLOCKED。

## 回測與比較
至少建立更長的歷史資料（理想含不同市場狀態），以逐時序 walk-forward / out-of-sample 做成本內含模擬；回報樣本數 N、勝率及不確定度、每筆淨期望值、Profit Factor、最大回撤、平均持有天數、成交率、交易成本占毛利比。未達可驗證樣本數不得虛構勝率。每週2–5筆僅作研究產能參考。觀察池股票同產業集中也需揭露。

## 帳本與每日收益（單一主要路徑）
使用 main:data/mode4_trade_ledger.json 為持久紀錄，保留 v3 舊 rounds、user_reported_real_positions 及既有 baseline；從 v4 生效日追加 v4_daily_reviews / v4_trade_events（沒有事件不要編造），不抹除歷史。
每筆 trade event 最少記錄：event_id（冪等）、market_date、source（user_reported_real / verified_paper_fill / simulation_only）、account（REAL/PAPER）、symbol、side BUY/SELL、shares、fill_price、gross_value、fees、tax、slippage、filled_at、evidence、linked_plan_id、timestamp、status。使用者沒有提供的費用標記 estimated 或 unknown，不得當成實際已驗證值。
每日結算分別計算 PAPER 與 REAL：期初現金、當日交易、現金、未平倉股數/成本、已實現淨損益、未實現損益（標明估值日／價格）、累計淨損益、equity、報酬率、最大回撤（需完整序列）。無法取得實際持倉或資金基數時，REAL 的帳戶總報酬標示 N/A，不可用 NT$100,000 硬算。未成交的 PAPER 淨損益為0。確認交易前不寫入 FILLED。
**已知實際持倉**：2026-10-28 使用者回報買入 2881 100 股，每股 NT$161，應沿用 user_reported_real_positions；不能把這100股算入 PAPER 交易。尚未核實券商費用和成交時間。

## 每日回覆最後的使用者確認
每個有效交易日分析結尾，主動請使用者回報「今天是否有依 Mode 4 買入／賣出？」；若有，請提供 股票代碼、買或賣、成交股數、成交均價、成交日期、券商手續費與證交稅（有則提供）、是否仍持有；若無請回覆「今日無交易」。不要求重複已記錄的 2881 買入。使用者回報後下一次對話/排程檢視回報並更新 GitHub ledger；**定時排程無法直接讀到尚未發生的使用者回覆，也不得聲稱已自動入帳**。每次寫入前重讀 ledger SHA，依 event_id 避免重複計算。每日簡報顯示（A）交易建議（B）兩本帳本損益（C）需要使用者確認的成交。
